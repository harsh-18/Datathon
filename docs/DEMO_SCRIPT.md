# KSP Datathon 2026 - Demo Script & Judge Presentation Walkthrough

**Target Presentation Time**: 3 to 5 Minutes  
**Problem Statement**: Problem Statement 2 - AI-Driven Crime Analytics & Visualization Platform  

---

## 🎬 Step-by-Step Presentation Script

### 1. Introduction & Context (30 Seconds)
- **Visual**: Show the **Executive Overview** screen on browser.
- **Narration**: *"Good morning judges. Today, Karnataka State Police maintains extensive crime records, but much analysis remains manual, Excel-based, and fragmented across police station silos. We present the KSP Crime Intelligence & Analytics Platform — a state-of-the-art operational dashboard deployed on Zoho Catalyst that moves SCRB from reactive reporting to proactive, evidence-based policing."*

### 2. State-Wide Threat Level & Anomaly Notice (45 Seconds)
- **Visual**: Point out top KPIs (5,070 Active FIRs, 5 Hotspots) and the glowing Red **Crime Spike Alert Banner** (`38.2% surge in transit-hub robbery across Bengaluru Urban and Tumakuru`).
- **Narration**: *"On the main dashboard, SCRB leadership gets instant visibility into state threat levels, top crime distributions, and automated anomaly alerts triggered when multi-station FIR spikes occur."*

### 3. District & Station Drill-Down (45 Seconds)
- **Visual**: Click **District Analytics** sidebar item. Select **Bengaluru Urban** card.
- **Narration**: *"Analysts can drill down into any of Karnataka's 10 key districts. Here in Bengaluru Urban, we see 1,420 registered FIRs, 42 connected police stations, and 14 active repeat offenders."*

### 4. Interactive Geospatial Hotspots (60 Seconds)
- **Visual**: Click **Geospatial Hotspots**. Zoom into Karnataka Leaflet map. Click on the red marker for **Bengaluru Urban** or **Tumakuru**.
- **Narration**: *"Our geospatial map renders crime hotspots dynamically. Clicking on Bengaluru Urban displays the top crime classification — snatching & theft — along with a recommended tactical police response: 'Deploy intensive night beats & ANPR checkpoint cameras'."*

### 5. Criminal Link Network Analysis (60 Seconds)
- **Visual**: Click **Network Link Graph**. Click on suspect node **Ravi Kumar @ Bullet Ravi**. Show the side inspector updating.
- **Narration**: *"The core value for field investigators lies in our Criminal Network Link Graph. Here we see repeat offender Ravi Kumar linked across multiple FIRs in Bengaluru Urban and Tumakuru, sharing modus operandi tags with accomplice Imran Shaikh. Clicking any node inspects direct associations in real-time."*

### 6. Explainable AI Risk Engine & Natural Language Query (45 Seconds)
- **Visual**: Show **AI Risk Engine** slider adjustments and **Ask Crime Data** query interface.
- **Narration**: *"Instead of black-box AI, our risk engine provides explainable attribution factors. Analysts can ask natural language questions or adjust factor weights dynamically. Finally, our entire platform is built natively for Zoho Catalyst deployment."*

---

## 🔑 Key Points To Emphasize To Judges
1. **Not a Marketing Landing Page**: This is a dense, working operational command dashboard built for police analysts.
2. **KSP Database Schema Parity**: Uses authentic KSP FIR formats (`CrimeNo`, BNS Sections, Heinous classifications).
3. **Catalyst Deployment Target**: Uses Catalyst Client Web Hosting & Serverless Express Functions.
